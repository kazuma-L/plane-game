

A vertical shoot-'em-up made with Python and pygame. Dodge and shoot down enemy planes coming from above. The longer you survive, the higher your score, and the more numerous and faster the enemies become.


1. Go to the [Releases page](https://github.com/kazuma-L/plane-game/releases)
2. Download the latest `plane-game-windows.zip`
3. Unzip it and double-click `plane-game.exe`

> Windows only. If SmartScreen shows a warning, click "More info" → "Run anyway".



Use W, A, S, D to move
Space to shoot(hold space bar to continuous fire)
R to restart after game over


Each enemy you shoot down gives 1 point
Every 5 points, one more enemy appears on screen
Enemies fall faster as your score grows
Colliding with an enemy ends the game


Requires Python 3 and pygame:


pip install pygame
python main.py
